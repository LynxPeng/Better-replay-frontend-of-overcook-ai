# Cafe surfaces

`CafeTile_BaseColor.png` and `CafeTile_Normal.png` are original, hand-authored
procedural assets generated by `Assets/Editor/InteriorMaterialAssets.cs`.
The four-by-four warm greige tile pattern repeats every four world units,
with one tile per metre, shared24mm grout, rounded corners, bevel normals,
a pale edge rim, strong light/dark variance and mottling in slightly warm greige.
No reference screenshot pixels are copied.
The user's Overcooked screenshot supplies colour and mood guidance.

`CafeCounter_Atlas.png` is generated **locally** from the user-supplied Restaurant
Bits Unity edition's palette. It adjusts surfaces to deeper orange-yellow only on
counter materials; food, cookware and other native props retain their original
palette. This derivative remains subject to the source package's Unity Asset
Store licence and is excluded from Git, like the source Store package. Its meta
file preserves the material reference. `ProjectBootstrap.Setup`/`Build` recreates
it after the licensed package has been installed locally.

The former CC0 wood floor and its material are retained in `Art/WoodPlanksGrey`
as optional art, outside Resources; the active restaurant uses these tiles.

The native cap and cabinet outer corners are rounded in memory, retaining UVs
and authored shading on unmodified panels. The native carcass footprint determines
front/back corners; no derived Store mesh is saved or committed.
